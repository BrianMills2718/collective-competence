# Competence research / Dynamical Laboratory

An integrated research programme with a constructive **Collective Competence** arm and an analytic **Goal and Competence Discovery** arm. The shared scientific question is now deliberately narrower than "can collectives be competent": the project asks which experimentally separable constraints determine goal-relative competence and failure boundaries, and which goal/competence claims are actually identifiable from behavior under a declared observation/intervention contract.

The programme is **reuse-first and interrogation-first**. Broad phenomena such as local-to-global morphogenesis, cellular competency, homeostatic goal scaling, bioelectric coordination, regeneration, reachability, and inverse inference already have substantial prior art. New work should therefore prefer independently authored executable systems and make risky intervention predictions rather than build another bespoke demonstration of an established primitive.
