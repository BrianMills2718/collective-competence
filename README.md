# Competence research / Dynamical Laboratory

This repository studies **which experimentally separable constraints determine goal-relative competence and failure boundaries of dynamical systems, and which candidate goals and competence claims are identifiable from behavior under a declared observation/intervention contract**.

The programme has two scientific arms: **Collective Competence** maps causally load-bearing constraints by intervention, while **Goal and Competence Discovery** asks what goal/competence structure remains identifiable under restricted access. The **Dynamical Laboratory** is shared apparatus.

**Start at the [project wiki](wiki/index.md).** For a return after a hiatus, read [current work](wiki/current.md) and [findings](wiki/findings.md), then follow the [experiment map](experiments/README.md) to native protocols, code, and evidence. Agents first read [AGENTS.md](AGENTS.md).
