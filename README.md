# Collective Competence / Dynamical Laboratory

An open-ended laboratory for discovering unexpected goals and competencies
across diverse systems.

**Enter through the [unified project wiki](roadmap/README.md).** It connects the
goal, apparatus, research findings and counterevidence, experiment register,
current plan, usage, and complete documentation catalog.

Agents first read [CLAUDE.md](CLAUDE.md), exposed through the generated
[AGENTS.md](AGENTS.md), then follow the wiki and applicable subtree rules.
Sorting is one calibration specimen—not the scope of the project.

[Current priorities and version boundary](goal-discovery/docs/plans/current_research_plan.md)
remain at their native owner. This README is a doorway, not a parallel status page.
