# Experiment 07 — endogenous size control separates amount from position

This specimen moves the stopping cue inside the tissue. Every cell secretes the same inhibitor; an edge cell senses the local steady-state concentration produced by the whole contiguous tissue. It never receives an explicit cell count or external coordinate.

The question is whether that self-produced signal can tell a tissue **how much** structure to regenerate after loss, and what it still cannot tell the tissue about **where** the missing structure belonged.

## System

A contiguous one-dimensional tissue lives far from the boundaries of a 200-site arena. The reference tissue has 24 cells. Each cell contributes an exponentially decaying inhibitor field; the concentration sensed at either tissue edge is

`I(n) = sum(exp(-d / lambda), d=0..n-1)`

for tissue size `n`.

Two thresholds are authored halfway between the edge concentrations for sizes 23/24 and 24/25. An edge cell proliferates outward when the sensed concentration is below the lower threshold and an edge cell is removed when it is above the upper threshold. Between thresholds the tissue is quiet. Which edge acts is chosen uniformly at random.

The baseline decay length is 12. The field is treated as already equilibrated after each structural event; finite diffusion time is not modeled here.

## Development and bidirectional size recovery

From one cell, the controller reaches size **24 after 23 structural operations** and stops. The resulting interval in the declared seed is 87–110 rather than the reference 88–111: the mechanism controls size, not absolute position.

Right-side amputations and right-side additions of 1, 2, 4, 8, 12, or 18 cells were each run for **2000 random edge-choice seeds**. Every one of the 24,000 challenge trials returned to size 24, with one birth/death per unit of size error.

Position tells a different story. After right amputation, exact return to the original interval requires every compensating birth to occur on the right. Observed exact-position recovery is consistent with the resulting `2^-width` expectation: **124/2000** at width 4, **12/2000** at width 8, and **0/2000** at widths 12 and 18. The excess-cell challenge shows the same pattern for random edge removal.

So this controller demonstrates size homeostasis, not positional regeneration. The distinction is not semantic: one performance dimension is perfect in the declared tests while the other collapses with challenge size.

## Causal signal controls

After an 8-cell amputation the tissue starts at size 16.

- **Clamp the sensed inhibitor to its pre-damage size-24 value:** no structural operation occurs and the tissue remains at 16. The post-loss signal drop is therefore necessary to reopen proliferation in this controller.
- **Set inhibitor secretion to zero:** the stop disappears. After the fixed 50-operation observation window the tissue has grown from 16 to **66 cells**.

These are mechanism controls for the authored controller, not proof that a biological tissue must use this molecule or architecture.

## Noise and decay-length boundary

The edge signal distinguishes adjacent sizes only by the contribution from the most distant cells. Short decay lengths therefore make the 23/24/25 concentrations nearly indistinguishable. With additive sensing noise sigma = **0.02**, 20 fixed seeds and 1800 scored steps per seed after burn-in give:

| decay length | target discrimination margin | fraction at size 24 | mean absolute size error |
|---:|---:|---:|---:|
| 4 | 0.00124 | 0.190 | 1.705 |
| 6 | 0.00916 | 0.513 | 0.519 |
| 8 | 0.02489 | 0.834 | 0.166 |
| 12 | 0.06767 | 0.999 | 0.00058 |
| 18 | 0.13180 | 1.000 | 0.000 |

The thresholds are recalibrated to make size 24 the quiet size at each decay length, so this sweep tests **whether the field carries enough size information under noise**, not whether one fixed controller adapts when lambda changes.

## Scope and interpretation

This is still a minimal engineered analogue. It assumes a contiguous tissue, instantaneous steady-state signaling, homogeneous secretion, and edge-only structural events. The threshold encodes the desired characteristic size. It does not show cells discovering that size, regenerating organizers, or reproducing a biological mechanism.

What is new relative to Experiment 06 is the source of the stopping information: the signal is generated by the tissue itself and changes causally when cells are lost or added. The experiment also gives a clean decomposition of competence: **size can be restored without position**, and signal range/noise limits how reliably size can be represented.

A natural next constructive test is composition: add a minimal polarity/positional cue to this endogenous size controller and ask whether “how much” and “where” can be combined without collapsing back into a complete external target map.
