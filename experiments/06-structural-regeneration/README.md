# Experiment 06 — positional information for structural regeneration

This is the first specimen in the current sequence with **actual vacancies and cell regrowth** rather than fixed sites whose state changes. It asks a narrow mechanistic question: what information lets local proliferation distinguish a wound that should be filled from a normal tissue boundary where growth should stop?

## System

A 64-site one-dimensional arena contains a contiguous 24-cell target tissue at sites 20–43. Cells can create a daughter only in an adjacent vacant site. There is no long-range movement, central controller, target list stored in a cell, or spontaneous cell creation.

The key information problem is visible before adding any positional cue. With occupancy alone, the right edge of an intact tissue and the right edge left after end amputation both have the same radius-1 signature `(occupied, occupied, vacant)`. A translation-invariant local occupancy rule therefore cannot assign opposite actions—stop versus regrow—to those two situations without another input.

Two fixed organizer signals are supplied from opposite arena boundaries. The principal controller uses their local **ratio** to define an accepted positional band. A matched control uses only the absolute left-gradient value and is calibrated to produce exactly the same 24-site tissue at baseline source strength. A third control permits ungated local proliferation.
## Formation and common-mode calibration

From one surviving seed cell, the ratio controller reconstructs the exact target under common source amplitudes `0.75`, `1.0`, and `1.25`. The single-gradient controller matches exactly only at its calibration amplitude `1.0`; at `0.75` it produces sites 15–37, and at `1.25` sites 25–47. Ungated local proliferation fills all 64 sites.

The ratio controller's common-mode invariance is not a deep emergent result: multiplying both signals by the same factor cancels in the ratio. Its role here is to provide a transparent positional-information baseline and a matched comparison to an absolute concentration code.

## Amputation and regrowth

The declared repair matrix crosses:

- left, right, and middle removal;
- widths 4, 8, and 12;
- common signal amplitudes 0.75, 1.0, and 1.25.

That gives **27 cases per controller**. The ratio controller restores the exact 24-site morphology in **27/27** cases and always adds exactly the number of cells removed. The baseline-matched single-gradient controller succeeds exactly in **9/27** cases—all at its calibration amplitude. Ungated proliferation succeeds in **0/27** because it cannot stop at the target edge.
## Fragment and information boundaries

The same ratio rule regenerates the complete target from **every possible single surviving target cell: 24/24 cases**. With zero surviving cells, no local proliferation can begin, so the empty state remains empty. This is a structural parent-cell requirement rather than a failure of positional inference.

Organizer information is also load-bearing. After a right-side width-8 amputation, removing the left source, right source, or both sources produces **zero births** under the ratio gate. `0/0` is explicitly treated as missing information rather than as a fictitious midpoint; a regression test protects that contract.

Changing the two organizer strengths unequally shifts the accepted region. For example, with left amplitude fixed at 1.0, right amplitudes `0.5, 0.75, 1.5, 2.0` produce different recovered morphologies. The ratio code is therefore robust to common-mode gain, not to arbitrary organizer imbalance.

## Interpretation

The result supports a narrow information claim: **local proliferation cannot infer “wound versus normal edge” from occupancy alone in this translation-invariant setting; supplying positional information resolves that ambiguity and permits exact regrowth.**

It does not establish autonomous morphogenesis. The coordinate map is supplied by external organizers, and the ratio thresholds are authored. The common-mode invariance is largely predictable on paper. This experiment is best treated as a mechanistic baseline for the next question: can the stopping variable be generated by the tissue itself rather than by a fixed external map?
