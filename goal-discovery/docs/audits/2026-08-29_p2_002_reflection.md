# P2-002 reflection and allocation audit — 2026-08-29

## What the sprint actually bought

P2-002 did more than produce a near miss. It changed the experimental object.
The original question treated the whole freeze factorial as one prediction
surface. The error audit showed that this mixes two different jobs:

1. predicting easy regimes where an intervention label already determines the
   outcome; and
2. predicting the hard boundary regimes where nominally identical damage can
   succeed or fail.

The broad no-go remains valid. Capability-aware log loss improved 18.9%, not the
frozen 20%, so size 24 was correctly withheld. The result nevertheless locates
where the candidate measurement has information value: late two/three-cell
moveable freezes and late one-cell immovable freezes.

## Time-allocation verdict

The highest-leverage next action is not another broad factorial, a new model, or
more visualization. It is a 72-branch new-seed test of the within-intervention
question using exactly the same generator, features, estimators, and gate.

This has high information value because either outcome changes the roadmap:

- a pass earns the first size-generalization batch;
- a failure retires the current capability representation and redirects work
  to observation design;
- failure to obtain mixed outcomes shows that the selected regimes are not a
  stable discrimination surface.

The test is cheap, deterministic, and reversible. No new dependency or
framework is justified.

## Allocation

- 15 minutes: freeze P2-002b design and eligibility rule;
- 20 minutes: implement by parameterizing the adopted P2-002 batch runner;
- 10 minutes: generate, score, and decide;
- up to 45 minutes: size-24 holdout only if promotion is earned;
- 15 minutes: synthesize and refresh the evidence surface only after the result.

The unchanged 20% threshold prevents the reflection from becoming a post-hoc
repair of P2-002.
