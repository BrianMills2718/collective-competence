# P3-001 reflection — adopt the generator, not the claim

## Audit

The spike met its purpose in less than one bounded sprint:

- no new simulator or frontend;
- unmodified installed NetLogo model, with source hash recorded;
- standard live visualization already available;
- external BehaviorSpace adapter produced paired raw trajectories;
- the frozen perturbation and late-recovery gates passed in all four seeds.

The key result is a disagreement between scales. The locally aligned state
recovered while global polarization remained lower. Building more visualization
or declaring “recovery” now would hide the scientific question rather than
answer it.

## Plan change

Freeze one representation-discrimination experiment before adding any new
model feature. Export the global heading vector as well as polarization and
local disagreement. Use four arms: baseline, quarter rotation, quarter rotation
with interaction disabled, and whole-flock rotation that preserves relative
alignment.

The whole-flock arm is decisive for the absolute-heading hypothesis: it changes
heading while leaving local alignment intact. The vision-off arm is decisive
for active collective recovery: it preserves individual motion but removes the
local information channel.

Only a representation that passes those contrasts may earn held-out
confirmation. Otherwise fall back to the installed Fireflies generator.
