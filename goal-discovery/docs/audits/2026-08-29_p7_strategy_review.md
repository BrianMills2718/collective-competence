# P7 strategic review: optimize for decisions, not activity

## First-principles test

The end goal is not more code, more simulations, or a polished interface. It is
a reusable ability to discover and validate useful observable descriptions of
dynamical systems. Work earns time only when it does at least one of:

1. resolves the current scientific uncertainty;
2. makes the next discriminating experiment materially cheaper or safer;
3. preserves evidence needed to prevent a false conclusion.

Implementation throughput is a constraint, not the progress metric. The useful
unit of progress is a decision that changes what the programme should fund next.

## What has moved the programme

- Seeded interventions, explicit observation boundaries, nulls, and held-out
  scoring now work across several generators.
- Different observation structures have earned task-specific value: temporal,
  relational, and identity-conditioned representations each have a positive
  calibration, while a network representation produced a useful abstention.
- Failed confirmations prevented exploratory effects from becoming claims.
- Off-the-shelf NetLogo, Panel/HoloViews, tsfresh, NetworkX, scikit-image, and
  Morpheus tests established that reuse can keep adapters thin.

## What consumed time without enough return

- Repeated generator and archive qualification eventually made ideal external
  evidence a prerequisite for any internal learning.
- UI mockups became ambiguous because they visualized a possible laboratory
  rather than the actual decision frontier.
- Some exploratory lines inherited confirmation-grade sample and boundary
  requirements before a cheap discriminating signal had been shown.

The corrective action is not to remove verification. It is to stage verification
so its cost rises only after the preceding evidence level passes.

## Changes made

- Replaced the archive-blocked roadmap with a decision ladder from calibration,
  to prospective selection, to naturalistic transfer, to macro causal/control.
- Defined Level 0–4 evidence so prototypes and promoted claims use different
  standards deliberately.
- Limited the cockpit to versioned state, evidence paths, and next decisions; it
  no longer justifies mock scientific machinery.
- Ran P7-001 from a committed protocol. Its 4/4 pass selected P7-002 rather than
  reopening archive search.
- Chose the installed, unmodified Virus on a Network model for P7-002: it is a
  fast standard visual generator with a genuinely new task and all four candidate
  observation structures.

## P7-002 time allocation

| Time | Work | Decision artifact |
|---:|---|---|
| 0–30 min | thin adapter and one real headless/visual trace | executable trajectory plus provenance |
| 30–60 min | Level 0 endpoint/intervention feasibility only | non-degenerate task or stop |
| 60–120 min | commit final settings; generate discovery groups; score all families | selected family or abstention |
| 120–160 min | mechanically open confirmation groups and frozen ablation | prospective score |
| 160–180 min | integrity attack, result note, cockpit update | pass, abstain, or fail |

This deliberately spends roughly one third on making the test real, one third on
discovery, and one third on untouched confirmation and decision. If an earlier
gate fails, the saved time is part of the design.

## Continuing audit rules

- Every active sprint names one scientific unknown and one decision it purchases.
- A UI addition must reduce time-to-understanding or time-to-decision on real
  evidence; otherwise it is deferred.
- A new dependency or generator must beat a thin reuse path on time to first
  discriminating artifact.
- Negative and abstention results count as progress when they close an investment
  branch under a frozen rule.
- At each sprint end, update the authoritative plan and cockpit state before
  starting more implementation.

The principal residual risk is that P7-001 encoded known task/family pairings.
P7-002 directly attacks that risk with automated family selection and untouched
confirmation networks. Until it passes, the programme should say it has a
calibrated selection surface—not autonomous representation discovery.
