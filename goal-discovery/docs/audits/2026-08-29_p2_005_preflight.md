# P2-005 preflight — opportunity-adjusted performance

## Decision value

P2-003 and P2-004 made another sorting-size enumeration low value. The next
question can still change the programme decision:

> When the goal is mechanically reachable, do different local rules reliably
> realize the available route?

If the answer is no, opportunity-adjusted performance is a useful quantity for
later goal-discovery experiments. If exact reachability explains every outcome,
the sorting generator is mechanically complete for the present agenda and the
programme should move to a richer system.

## Reuse survey

Use NetworkX `DiGraph`, `has_path`, and unweighted `shortest_path_length` for the
state graph. NetworkX is maintained, its current documentation explicitly
supports directed unweighted reachability, and version 3.6.1 is already in this
repository's lockfile through the completed Mesa spike. Promoting it to a core
dependency is smaller than importing Mesa or building a graph library.

Primary reference:
<https://networkx.org/documentation/stable/reference/algorithms/shortest_paths.html>

No dashboard, graph database, causal-emergence package, or new simulator is
needed. Custom code is limited to translating the existing local rules into
observable state transitions and producing the frozen comparison table.
