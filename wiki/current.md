# Current work

[Wiki home](index.md) · [Questions](questions.md) · [Findings](findings.md) · [Laboratory](laboratory.md)

This is the only hot page that owns **current priority and next action**.

## Where we are

The project now has actual component-loss/regrowth as well as fixed-site pattern repair. Experiment 06 makes the stopping problem explicit: with occupancy alone, a normal tissue edge and a wound edge have the same local signature, so local proliferation needs some additional information to know where growth belongs.

A pair of external organizer gradients supplies that information in the simplest possible way. Relative signal encoding regenerates the same 24-site tissue after all declared amputations and ignores common-mode source-strength changes; an absolute single-gradient code drifts, and ungated growth does not stop. Relative source imbalance remains a failure boundary.

This is a useful constructive result but deliberately not autonomous regeneration: the organizers provide a fixed coordinate map. The next question is how much of the stopping information can be generated by the tissue itself.

## Next action

**Build the smallest endogenous size/stopping-control specimen.**

A good first candidate is a contiguous one-dimensional tissue whose cells produce a shared inhibitory or quorum-like signal. Edge cells may proliferate after loss when the sensed signal is below a threshold; as total tissue recovers, the signal should rise and shut growth off. The point is not biological realism yet, but moving the stopping variable from a fixed external position map into the collective itself.

The first questions are:

1. Can the tissue recover a characteristic size after partial amputation using only a signal generated by its own cells?
2. Does the signal fall after cell loss and causally reopen proliferation, then rise enough to stop it again?
3. What control shows that the result is size sensing rather than a fixed growth schedule or arena boundary?
4. How does diffusion/decay or sensing noise limit the size range over which the cue remains informative?
5. Does the system restore size only, or also position/shape? Keep those claims separate.

Start white-box and minimal. Do not build a general morphogenesis framework or another Goal Discovery analyzer first.

## Working rules

- Optimize for **different phenomena learned per unit effort**.
- Prefer minimal, inspectable biological analogues over realism for its own sake.
- Construction and mechanism first; discovery analysis second.
- State clearly which information is external, internal, local, or shared.
- Distinguish size restoration, positional restoration, pattern restoration, and functional restoration.
- Add apparatus only when a concrete experiment requires it.
- Negative results and information/feasibility boundaries count as progress.
- Preserve native evidence without creating parallel status surfaces.

## Secondary follow-ups

Experiment 06 could later support a blind test of positional-criterion inference, but that is not the scientific front: its authored mechanism is already transparent. The many-state coloring specimen remains the stronger example for non-unique candidate goals. The retained morphogenesis scaling work may inform diffusion/noise choices for the endogenous signal, but it should not be copied into the new experiment as a conclusion.
