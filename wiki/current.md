# Current work

[Wiki home](index.md) · [Questions](questions.md) · [Findings](findings.md) · [Laboratory](laboratory.md)

This is the only hot page that owns **current priority and next action**.

## Where we are

The regeneration sequence now separates several requirements that were easy to conflate: positional cues, amount/size, wound identity, intrinsic composition, generative plasticity, reporter integrity, and memory.

Experiment 10 showed that type-specific self-produced signals can replace a composition oracle for partial repair, but its healthy A/B setpoints were still authored constants. Experiment 11 removes those target-count constants from repair. A slow extracellular trace learns the healthy A and B signal levels from pre-damage history and then serves as the remembered setpoint.

The same controller learns healthy compositions `A^6 B^18`, `A^8 B^16`, and `A^10 B^14`. With persistent memory and fate plasticity it restores all **12/12** declared partial/extinction challenges. Memory decay creates a real horizon: exact repair across those 12 challenges falls from **12/12** at retention 1.0 and 0.9995 per birth to 11/12 at 0.999, 8/12 at 0.998, and 4/12 at 0.995. Without plasticity, complete A/B extinction remains unrepaired in **0/6** declared cases.

The learned setpoint also clarifies the reporter-failure problem. If A secretion fails in an otherwise intact tissue, no wound is present and the controller correctly performs no growth. But if structural A damage and A-reporter failure occur together, the remembered target remains high while the current A signal never recovers, so the controller overgrows for the full observation window. **Remembering the desired state does not authenticate the sensor reporting the current state.**

## Next action

**Formulate the current-state fault-identification problem before adding a redundant reporter.**

The next mechanism must earn its existence by distinguishing at least these cases:

1. true A loss with a functioning A reporter;
2. intact A tissue with A reporter/secretion failure;
3. A loss and A reporter failure occurring together;
4. recovery after A lineage extinction, where fate plasticity may be available but current A abundance still needs a trustworthy stop signal.

A second measurement channel is useful only if its failure mode is meaningfully independent. Adding “another A signal” that is generated by the same cells and fails for the same reason would not solve the scientific problem; it would only duplicate the representation.

Questions to answer before implementation:

1. What independent observable of current A abundance can survive or remain informative when A's own secretion channel fails?
2. Can surviving B cells or an extracellular structure sense A abundance without storing the full target count or coordinate map?
3. Is a wound event plus growth-history counter enough for the declared end-amputation challenges, and if so what challenge makes that shortcut fail?
4. What joint failure patterns make structural loss and reporter failure fundamentally indistinguishable under the available observations?
5. Can we state an identifiability limit before simulation: which combinations of hidden structural state and reporter state map to the same observations?

The fifth question should be answered on paper first. If two hidden states are observationally equivalent under every available intervention, adding a controller cannot solve the ambiguity without adding information.

## Working rules

- Optimize for **different phenomena learned per unit effort**.
- Prefer minimal, inspectable biological analogues over realism for its own sake.
- Construction and mechanism first; discovery analysis second.
- Keep desired-state memory separate from current-state measurement.
- Keep pattern, size, location, composition, reporter integrity, fault diagnosis, memory, plasticity, and exact microstate distinct.
- Treat translations or other symmetries as equivalent unless the experiment explicitly supplies a reason not to.
- State which information is external, tissue-generated, inherited, local, shared, historical, persistent, or supplied by oracle.
- Do not call duplicated channels redundant unless their failure modes are independently challenged.
- Do not simulate a claim whose decisive content is already derivable on paper; use analytic identifiability arguments first.
- Add apparatus only when a concrete experiment requires it.
- Negative results, corrections, and information/feasibility boundaries count as progress.

## Secondary follow-ups

The learned-memory retention sweep can later be extended with noise or delayed repair if a concrete memory-lifetime question requires it. For now, the more important issue is that a remembered target plus a single fallible reporter cannot identify every combination of structural damage and reporter failure.
