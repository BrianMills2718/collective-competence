# Scientific Hypergraph extraction

The general Scientific Hypergraph metamodel / semantic IR now lives in its own repository:

- **Authority:** `BrianMills2718/scientific-hypergraph`
- **Repository:** https://github.com/BrianMills2718/scientific-hypergraph
- **Default branch:** `main`

Scientific Hypergraph is the authority for the general AI-facing scientific IR, shared schemas, validators, query tooling, conformance corpus, and debug viewer.

Collective Competence is now a downstream scientific proving ground / consumer. CC-specific theory, experiments, substrates, evidence, and generated CC graph instances remain in this repository.

The original development history is retained in branch `docs/scientific-metamodel` and PR #79, which is superseded by the standalone repository and should not be merged into `main`.
